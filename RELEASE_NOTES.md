# История изменений (Release Notes)

## Версия 0.16.4 (2026-08-20)

*Постоянно видимый поиск по ячейкам и быстрый переход к поиску вкладок.*

### ✨ Новые возможности

- Поиск по содержимому ячеек теперь всегда виден в верхней панели рядом с полем номера и по-прежнему активируется по `Ctrl+F`.
- Поле поиска по вкладкам появляется при нажатии `Tab` в поле поиска по ячейкам.

### 🛠 Улучшения

- Поле номера сужено до трёх цифр (максимум 500 ячеек), кнопка очистки укорочена до «Очистить».

## Версия 0.16.3 (2026-08-19)

*Оформление поля заметки согласовано с фоном и выделением ячейки.*

### 🛠 Улучшения

## Версия 0.16.2 (2026-08-09)

*Длинный текст ячейки отображается от верхней границы области содержимого.*

## Версия 0.16.0 (2026-08-09)

*Релиз добавляет короткие заметки к ячейкам и отделяет долговременные пользовательские данные от временной истории буфера.*

### ✨ Новые возможности

- У каждой ячейки во всех вкладках появилось компактное редактируемое поле заметки рядом с номером.
- Заметка сохраняется отдельно от содержимого, участвует в поиске и не вставляется в системный буфер.
- Пользовательские вкладки, их ячейки, заметки, закрепления и блокировки приёма копирования теперь хранятся в `settings.json`, который можно переносить как резервную копию долговременных данных.

### 🐛 Исправления ошибок

- Добавлена миграция: пользовательские вкладки из прежнего `clipboard_history.txt` автоматически переносятся в `settings.json` при первом запуске новой версии.
- Сохранение истории больше не отбрасывает заметки ячеек.

### 🛠 Улучшения

- `clipboard_history.txt` теперь содержит только временные системные вкладки `Буфер` и `Фото`.
- Обновление portable-версии сохраняет `settings.json`, историю и локальные изображения пользователя.

## Версия 0.15.0 (2026-05-20)

*Релиз стабилизирует вставку сохраненных изображений в редакторы, папки Windows и на рабочий стол с сохранением исходного имени файла.*

### ✨ Новые возможности

- Для изображений, скопированных как локальные файлы, сохраняется исходное имя файла и отображается в ячейке FastClip.
- При выборе сохраненного изображения FastClip кладет в системный буфер bitmap и файловый `CF_HDROP`/`file://` payload с исходным именем, чтобы вставка работала не только в редакторах, но и в проводнике Windows.
- Добавлено runtime-логирование в `FastClip.log`: старт приложения, хоткей, выбор ячейки, запись буфера, возврат фокуса и отправка `Ctrl+V`.

### 🐛 Исправления ошибок

- Исправлена вставка изображения в папку после удаления уже вставленного файла: Windows Shell теперь получает явный `Preferred DropEffect=Copy`.
- Исправлена вставка изображения на рабочий стол: обработка `Progman`/`WorkerW` и `SysListView32` больше не падает на конвертации `HWND`.
- Исправлен запуск из глобального/консольного Python: `fastclip.pyw` автоматически перезапускается через проектный `.venv\Scripts\pythonw.exe`.
- Собственные clipboard-записи FastClip теперь игнорируются при обратном чтении, поэтому изображение не переименовывается на служебный hash после вставки.

### 🛠 Улучшения

- Вкладки получили дополнительный внутренний отступ для кнопок блокировки копирования и закрытия вкладки.
- Добавлены тесты для имени изображения, export-файлов, Windows clipboard payload и конвертации `HWND`.
- Сборочный pipeline больше не копирует локальную историю буфера, изображения, настройки и логи в релизную папку и не запускает приложение после `post_build.py`.
- Добавлены release-скрипты для создания установщика через Inno Setup и обновления локальной portable-папки.

## Версия 0.14.0 (2026-02-20)

*Релиз сохраняет состояние вкладок между перезапусками и стабилизирует восстановление tab-overflow панели.*

### ✨ Новые возможности

- Добавлено сохранение состояния вкладок в `settings.json`: порядок вкладок, активная вкладка и `preferred_overflow_tab`.
- При запуске состояние вкладок теперь объединяется из `clipboard_history.txt` и `settings.json`: пользовательский порядок восстанавливается, отсутствующие вкладки создаются автоматически, вкладки из истории добавляются в конец.
- Предпочтительная скрытая вкладка (`▼`) сохраняется между сессиями и учитывается при перестроении панели вкладок.

### 🐛 Исправления ошибок

- Исправлен сценарий, где после перезапуска выбор вкладки в overflow мог сбрасываться: при пустом `preferred_overflow_tab` используется активная пользовательская вкладка, а для системной активной вкладки применяется сохранённое предпочтение.

### 🛠 Улучшения

- Добавлен модуль `app/core/tab_state_resolver.py` для детерминированного merge истории и настроек вкладок.
- Расширен `SettingsService`: добавлены `load_tabs_state`/`save_tabs_state` с нормализацией данных и защитой от некорректных значений.
- Добавлены тесты `tests/test_tab_state_resolver.py`, `tests/test_settings_service.py`, `tests/test_app_controller_persistence.py`; расширены тесты `tests/test_tab_visibility.py`.
