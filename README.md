# FastClip

Менеджер буфера обмена для Windows на `Python + PySide6`.

**Текущая версия: `0.16.4`**

## О проекте

`FastClip` работает в системном трее, автоматически собирает историю буфера обмена (текст и изображения) и открывает popup для быстрой вставки выбранного элемента.

## Ключевые возможности

### 1. Захват и хранение буфера

- Изменения буфера (`Ctrl+C`/`Ctrl+X`) автоматически добавляются в историю.
- История сохраняется между перезапусками в `clipboard_history.txt` (лимит: 500 фрагментов).
- Поддерживаются текст и изображения (скриншоты и скопированные image-файлы).
- Для изображений, скопированных как локальные файлы, сохраняется исходное имя файла.
- Изображения сохраняются в `clipboard_images/`, в списке показываются миниатюры, при вставке передаётся полное изображение.

### 2. Вкладки и overflow

- Системные вкладки: `Буфер` (всегда принимает копирование) и `Фото` (принимает только изображения).
- Пользовательские вкладки: создание (`+`), переименование, закрытие (`×`), блокировка приёма копирования (скрепка).
- При нехватке ширины используется overflow-кнопка `▼` с выпадающим списком скрытых вкладок.
- Выбранная через `▼` вкладка запоминается как предпочтительная скрытая.
- Состояние вкладок (`порядок`, `активная`, `preferred overflow`) сохраняется в `settings.json` и восстанавливается при старте.

### 3. Работа с элементами

- Вставка по клику, `Enter`, номеру (`Enter`) и из поиска.
- Изображения вставляются в редакторы как bitmap, а в папки Windows и на рабочий стол как файл с сохраненным именем.
- После вставки выбранный элемент поднимается в начало активной вкладки (с сохранением блока закреплённых).
- Режим `Alt+ЛКМ`: вставка без закрытия popup.
- Массовые и точечные удаления: `Ctrl+A`, `Ctrl+ЛКМ`, `Del`, `ПКМ`.
- `Очистить всё` очищает только активную вкладку, закреплённые элементы остаются.
- У каждой ячейки есть короткая заметка рядом с номером; она сохраняется отдельно от копируемого содержимого.

### 4. Поиск и навигация

- `Ctrl+F` открывает два поля: `Поиск по ячейкам` и `Поиск по вкладкам`.
- `Tab` переключает фокус только между этими двумя полями.
- В поиске по вкладкам `Enter` активирует найденную вкладку и показывает её на панели.
- При активном popup стрелки `←/→` переключают только видимые вкладки панели.

### 5. UI и системные сценарии

- Иконка в трее с меню: `Показать буфер`, `Настройки`, `Пауза`, `Выход`.
- Режим `Пауза` временно отключает реакцию на глобальный хоткей.
- Стабилизирована первая активация popup после запуска (фокус приходит с первого хоткея).
- Геометрия popup и окна настроек сохраняется в `settings.json`.
- Автозапуск Windows управляется через ярлык в `Startup` без всплывающего окна PowerShell.

## Быстрый запуск

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Start-Process .\.venv\Scripts\pythonw.exe -ArgumentList ".\fastclip.pyw"
```

## Горячие клавиши

- Глобальный хоткей открытия popup: `SC01D + SC010` (скан-коды, независимо от раскладки).
- В popup:
- `Ctrl+F` — открыть/показать поиск.
- `Enter` — вставка выбранного элемента.
- `Alt+ЛКМ` — вставка без закрытия popup.
- `Ctrl+A`, `Ctrl+ЛКМ`, `Del`, `ПКМ` — выделение и удаление.

## Файлы данных

- `settings.json` — настройки и геометрия окон, а также пользовательские вкладки с их ячейками и заметками. Этот файл можно переносить как резервную копию долговременных данных.
- `clipboard_history.txt` — только временная история системных вкладок `Буфер` и `Фото`.
- `clipboard_images/` — локальные файлы изображений.

## Ограничения
