<h1 align="center">FastClip</h1>
<p align="center">История текста и изображений из буфера обмена с быстрой вставкой в Windows.</p>
<p align="center"><a href="README.en.md">English</a> · <a href="https://github.com/Frommer-droid/FastClip/releases/latest">Последний релиз</a></p>

FastClip работает в системном трее и сохраняет скопированный текст и изображения. Откройте всплывающее окно горячей клавишей, найдите нужный фрагмент и вставьте его в активное приложение.

## Установка

Скачайте установщик со [страницы последнего релиза](https://github.com/Frommer-droid/FastClip/releases/latest) и запустите его в Windows. После запуска приложение появится в системном трее. Для открытия истории нажмите глобальное сочетание `SC01D + SC010` (скан-коды клавиш, независимые от раскладки). Выберите фрагмент мышью или клавишей `Enter`.

Для запуска из исходников нужны Windows, Python 3.12 и зависимости из `requirements.txt`:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Start-Process .\.venv\Scripts\pythonw.exe -ArgumentList ".\fastclip.pyw"
```

## Возможности

- История текста и изображений, миниатюры и поиск по содержимому.
- Системные вкладки «Буфер» и «Фото», а также пользовательские вкладки с закреплением элементов и короткими заметками.
- Вставка изображения в редактор или папку Windows с сохранением исходного имени файла, если изображение было скопировано как файл.
- Автозапуск, управление из трея и сохранение состояния между запусками.

Настройки и пользовательские вкладки хранятся в `settings.json`; история системных вкладок — в `clipboard_history.txt`, изображения — в `clipboard_images/`. Эти файлы создаются локально и не входят в репозиторий. Буфер обмена может содержать чувствительные данные: учитывайте это при использовании истории и резервном копировании.

Приложение использует Windows API и предназначено для Windows. Команды проверки и сборки описаны в [DEVELOPER.md](DEVELOPER.md). Изменения версий — в [RELEASE_NOTES.md](RELEASE_NOTES.md).
