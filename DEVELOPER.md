# DEVELOPER

## Текущая версия
`0.16.4`

## Назначение проекта
`FastClip` — Windows-приложение на `Python + PySide6` для накопления фрагментов буфера обмена и быстрой вставки выбранного фрагмента.

## Структура проекта
- `fastclip.pyw` — точка входа, инициализация `QApplication`, иконки и контроллера.
- `VERSION` — единый источник версии приложения.
- `LICENSE` — MIT-лицензия собственного кода; post-build копирует её в portable-папку, а сборщик установщика требует её наличия.
- `settings.json` — пользовательские настройки и геометрия окон (создается/обновляется автоматически), включая `tabs_state` (`order`, `active_tab`, `preferred_overflow_tab`) и `user_tabs` (пользовательские вкладки с ячейками, закреплениями, блокировкой приёма копирования и короткими заметками).
- `clipboard_history.txt` — файл временной истории системных вкладок `Буфер` и `Фото` (JSON: элементы `text`/`image`, для изображений сохраняется `image_name`, у ячеек — короткое поле `note`; создается автоматически). Пользовательские вкладки в него больше не записываются.
- `clipboard_images/` — локальное хранилище изображений из буфера (создаётся автоматически).
- `app/version.py` — чтение версии для dev/frozen режимов.
- `app/core/` — оркестрация сценариев приложения.
- `app/core/clipboard_store.py` — in-memory хранилище вкладок буфера, закрепления элементов, коротких заметок ячеек во всех вкладках, системных вкладок `Буфер`/`Фото`, блокировки приёма копирования по вкладкам и переноса выбранного при вставке элемента в начало активной вкладки.
- `app/core/tab_state_resolver.py` — merge состояния вкладок из `clipboard_history.txt` и `settings.json` с нормализацией порядка вкладок и выбором активной вкладки.
- `app/services/` — инфраструктура (hotkey, буфер, ввод, tray, настройки, окно foreground).
- `app/services/settings_service.py` — чтение/запись `settings.json`, включая `tabs_state` для восстановления порядка/активной вкладки и preferred-overflow вкладки.
- `app/services/window_service.py` — расширенная активация окна через WinAPI (foreground + attach thread input).
- `app/services/clip_history_service.py` — чтение/запись истории буфера.
- `app/services/clip_image_service.py` — сохранение изображений в локальную папку, export-файлы для Windows Shell, загрузка и очистка неиспользуемых файлов.
- `app/services/clipboard_service.py` — чтение payload из буфера (`text`/`image`/`urls`) и запись текста/изображения.
- `app/services/logging_service.py` — файловое runtime-логирование в `FastClip.log` рядом с exe/скриптом; логируются старт, hotkey, выбор ячейки, clipboard-write, активация целевого окна и отправка `Ctrl+V`.
- `app/services/auto_start_service.py` — управление автозапуском Windows через ярлык в Startup.
- `app/ui/` — окна интерфейса.
- `app/ui/popup_window.py` — вкладки буфера, pin-toggle, блокировка вкладки (скрепка), закрытие вкладки (`×`), переименование вкладки, двухполосный поиск (`Поиск по ячейкам`/`Поиск по вкладкам`) по `Ctrl+F`, фильтрация, вставка из поиска, активация вкладки из поиска по `Enter`, поддержка миниатюр изображений, работа со списком и автофокус первой строки при открытии popup; во всех вкладках рядом с номером ячейки рисует click-to-edit поле короткой заметки; вставка по клику обрабатывается в `mousePressEvent`; панель вкладок работает в одну строку с overflow-кнопкой `▼` и выбором скрытых вкладок через тёмное выпадающее меню; системные вкладки `Буфер` и `Фото` закреплены слева и не сокращаются по тексту; переключение `←/→` выполняется только по видимым вкладкам панели; умеет принимать и отдавать `preferred overflow` вкладку.
- `app/services/tray_service.py` — контекстное меню трея, включая переключатель `Пауза` для временного отключения реакции на глобальный хоткей.
- `app/ui/settings_window.py` — окно настроек с вкладкой `System`.
- `app/config/` — константы.
- `Build_Tools/` — инструменты сборки и post-build обработки.
- `00_CrRel_setup.pyw` — создание Windows-установщика через Inno Setup из готовой папки `FastClip/`.
- `00_Move.pyw` — обновление локальной portable-папки `D:\Portable_soft\FastClip` из готовой папки `FastClip/`.
- `tests/` — локальные автотесты (`unittest`/`pytest`) для предотвращения регрессий в логике вкладок, merge состояния вкладок и сохранения состояния в `settings.json`.

## Локальный запуск
```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Start-Process .\.venv\Scripts\pythonw.exe -ArgumentList ".\fastclip.pyw"
```

## Зависимости
- `PySide6-Essentials` используется вместо полного `PySide6`, потому что проекту нужны только базовые модули `QtCore`, `QtGui` и `QtWidgets`; `PySide6-Addons` не требуется.
- `PyInstaller` указан в `requirements-dev.txt` и используется только для локальной сборки релиза.

## Локальные проверки
```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m ruff check .
$env:QT_QPA_PLATFORM='offscreen'; .\.venv\Scripts\python.exe -m unittest discover -v
$env:QT_QPA_PLATFORM='offscreen'; .\.venv\Scripts\python.exe -m pytest -q
```

## Версионирование
- `VERSION` — единственный источник истины версии (SSOT).
- Все пользовательские упоминания версии должны синхронизироваться с `VERSION` при релизе (`README.md`, `DEVELOPER.md`, релизные заметки).
- В коде используется `from app.version import __version__`.
- Для сборки версия включается внутрь exe через `Build_Tools/FastClip.spec` (файл `VERSION` в `datas`).

## Сборка
1. Откройте `Build_Tools/SpecCompiler.pyw`.
2. Выберите `Build_Tools/FastClip.spec`.
3. Запустите сборку.
4. `Build_Tools/post_build.py`:
   - переносит результат в корень проекта (`FastClip/`);
   - копирует релизные ресурсы (`VERSION`, `logo.ico`, `LICENSE`) в папку приложения;
   - создает `RUNTIME_MANIFEST.json`;
   - удаляет временные папки;
   - не копирует `settings.json`, `clipboard_history.txt`, `clipboard_images/` и логи;
   - не запускает собранное приложение.
5. Для установщика после сборки запустите `.\.venv\Scripts\python.exe .\00_CrRel_setup.pyw`; результат создается на системном рабочем столе как `FastClip_vX.Y.Z_Setup.exe`.
6. Для обновления локальной portable-папки запустите `.\.venv\Scripts\python.exe .\00_Move.pyw`; целевой путь — `D:\Portable_soft\FastClip`.

## Принципы разработки
- Точка входа остается минимальной.
- `fastclip.pyw` до импортов PySide6 перезапускает ошибочный старт из глобального/консольного Python через `.\.venv\Scripts\pythonw.exe`.
- Логика добавляется в соответствующие модули внутри `app/`.
- Новые настройки сохраняются в корневой `settings.json`.
- Для клавиатурной отправки на Windows использовать только скан-коды через `SendInput`.
- Глобальный хоткей popup: комбинация `SC01D + SC010` через низкоуровневый hook `SetWindowsHookEx`.
- Глобальный хоткей открывает popup и не выполняет автоматический `Ctrl+C`.
- Первая активация popup после старта выполняется через отложенный вызов и повторные попытки foreground-активации.
- Буфер поддерживает два типа элементов: текст и изображение.
- Копирование файлов/папок (`file://...`) не сохраняется в историю как текстовый элемент.
- Изображения из clipboard сохраняются в `clipboard_images/` и вставляются как полноразмерные изображения.
- Если изображение скопировано как локальный файл, имя файла сохраняется в `image_name` и показывается в ячейке вместо общего заголовка `Изображение`.
- При выборе сохраненного изображения приложение кладет в системный буфер bitmap, `CF_HDROP`/`file://` ссылку на export-файл в `clipboard_images/_paste_exports/` с сохраненным `image_name` и Windows shell-формат `Preferred DropEffect=Copy`, чтобы вставка работала в редакторах, папках Windows и на рабочем столе без hash-имени.
- Собственные clipboard-записи при вставке из popup игнорируются при обратном чтении, чтобы выбранное изображение не переименовывалось на служебный файл.
- Системная вкладка `Буфер` всегда принимает копирование.
- Системная вкладка `Фото` всегда принимает только изображения и располагается сразу справа от `Буфер`.
- Для пользовательских вкладок копирование зависит от активной вкладки и её статуса блокировки (скрепка); текст в `Фото` не записывается.
- Очистка и удаление работают в контексте активной вкладки; закрепленные элементы не удаляются bulk-операциями.
- Закреплённые элементы удерживаются в начале списка; новые не закреплённые вставляются ниже закреплённых.
- Любая вставка из popup (клик, номер + `Enter`, поиск + `Enter`) поднимает выбранный элемент в начало активной вкладки с сохранением pinned-префикса.
- У ячеек всех вкладок есть короткая заметка (до 120 символов): она редактируется прямо в ячейке, сохраняется в истории, участвует в поиске и не передается в системный буфер при вставке. Повторное копирование уже существующей ячейки сохраняет её заметку и закрепление.
- После клика по ячейке popup скрывается, приложение несколько раз возвращает фокус в окно и child-focus, которые были активны до хоткея; если Windows вернул `GetForegroundWindow=0`, используется desktop shell target, для рабочего стола фокусируется `SHELLDLL_DefView/SysListView32`, и только затем отправляется `Ctrl+V`.
- Поиск в popup: `Ctrl+F`, live-фильтрация, автоактивация первой найденной строки, вставка `Enter`.
- Поиск по `Ctrl+F` включает два поля (`Поиск по ячейкам` и `Поиск по вкладкам`), `Tab` циклически переключает фокус между ними.
- В поле поиска вкладок `Enter` активирует найденную вкладку и выводит её в видимую часть панели вкладок.
- При активном popup стрелки `←/→` переключают только видимые вкладки буфера.
- Для последовательной вставки доступен режим `Alt+ЛКМ` по ячейке: вставка выполняется без закрытия popup (поочерёдное зажатие `Alt`).
- При открытии popup фокус всегда устанавливается на первый элемент списка, прокрутка возвращается к верхней строке.
- Автозапуск через `auto_start_service` выполняется в тихом режиме, без показа окна PowerShell.
- В dev-режиме `auto_start_service` запускает `fastclip.pyw` через `pythonw.exe` (если доступен), чтобы исключить консольное окно.
- Временная остановка глобального хоткея управляется из трея (`Пауза`) и применяется без перезапуска приложения.
- При персисте истории всегда синхронизируется `tabs_state` в `settings.json`: порядок вкладок, активная вкладка и preferred-overflow вкладка.
